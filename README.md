# LeadRelay — ТЗ на маршрутизацию лидов

Техническое задание на сервис (фронт + бэк), который принимает заявки из Instagram Lead Ads и TikTok Lead Generation, показывает их в таблице и пересылает в Telegram-бот и Telegram-канал, выбранные для рекламной кампании.

## Документы

- Канонический текст: [docs/TZ.md](docs/TZ.md)
- Читаемая версия с макетами экранов: этот сайт (`npm run dev`)

## Как открыть ТЗ локально

Нужны Node.js 20+ и npm.

```bash
npm install
npm run dev
```

Сайт откроется на порту `43127`. Сборка:

```bash
npm run build
npm run preview
```

## Что должно быть реализовано по ТЗ

1. В сервис приходят лиды с Instagram и TikTok (вебхуки).
2. В админке — таблица запросов. Отдельный набор колонок для Instagram и для TikTok.
3. CRUD внутренних кампаний, Telegram-ботов и Telegram-каналов.
4. У кампании выбираются бот и канал: новые лиды этой кампании уходят в Telegram.

Реализация самого сервиса в этот репозиторий не входит — здесь постановка для команды разработки.
